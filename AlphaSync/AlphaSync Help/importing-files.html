AlphaSync Help

Add or replace text on your Neo

Use a plain-text file on your Mac to add writing to AlphaWord or the user dictionary. Other applet formats are read-only.

Add a new file

  1. Choose the intended Neo and editable applet in the sidebar.
  2. Clear the file selection by clicking an empty part of the list.
  3. Choose File → Import Text Files to Neo…, select one or more plain-text files, and confirm your choice.
  4. Wait for the operation to finish and check the file list.

You can also drop plain-text files into an empty part of the list. Check the applet and file selection first. New AlphaWord files are unbound: they are not assigned to one of the Neo’s file keys. Use the Neo’s Open command to find them.

Replace an existing file

Before replacing: save a backup of important writing. Replacement changes the text on your Neo and cannot be undone with Edit → Undo.

  1. Select the Neo file you want to replace.
  2. Choose File → Import Text Files to Neo… and choose one text file, or drop one text file onto the Neo file’s name.
  3. Check the named file in the warning. Keep Save a recovery copy first selected if you want to retain the original.
  4. Choose Replace to proceed, or Cancel to keep the file as it is.

Cancel has the initial keyboard focus. A requested replacement stops if its recovery copy cannot be saved. Keep your Neo connected until writing and verification finish.

Import dictionary words

Use simple words separated by spaces or line breaks. Duplicate words are stored once. Words must contain 2 to 20 supported characters.

If some words cannot be used, AlphaSync shows their count and examples. Choose Continue to import the usable words, or Cancel to leave that file unchanged. Replacing a dictionary still needs the separate Replace confirmation. A non-empty source with no usable words is rejected.

If a batch stops, earlier files that were already added remain on the Neo. Read the message before repeating an import. Editing a warned source may require a fresh review.

If Import is unavailable

Choose AlphaWord or the user dictionary, then select no files to add text, or exactly one file to replace it. Wait for any active operation or confirmation to finish. Save rich-text documents as plain text before importing them.

Names must use 1 to 15 supported characters. Oversized text, unsupported characters, or insufficient memory stop the change. See the text-format guide for ways to resolve these problems.
