AlphaSync Help

Open AlphaSync when you connect a Neo

AlphaSync can open when you connect your Neo, without opening the app yourself each time.

  1. Keep one copy of AlphaSync in your Applications folder.
  2. Choose AlphaSync → Settings….
  3. Turn on Open AlphaSync when a Neo is connected.
  4. Read the status below the switch. If approval is required, click Open Login Items Settings and allow AlphaSync’s helper in the system settings.

The switch shows your requested choice; the status tells you whether macOS has finished enabling it. Return to AlphaSync after changing the system setting to check the updated status.

If the app does not open

Open AlphaSync yourself and check the status in Settings. Keep the helper inside the complete app bundle. If it is reported missing, reinstall the app in Applications and enable automatic opening again.

If an older installation starts a separate helper from Application Support, turn off that old installation’s automatic-opening option before replacing it. If a connection still fails after sleep or reconnection, use Refresh or Try Again in AlphaSync.

Turn automatic opening off

Turn off Open AlphaSync when a Neo is connected in AlphaSync Settings. The helper only opens the app; file transfers happen in AlphaSync.
