AlphaSync Help

Opening AlphaSync automatically

  1. Put AlphaSync in Applications before enabling automatic opening.
  2. Open AlphaSync → Settings… and enable Open AlphaSync when a Neo is connected.
  3. If approval is required, use Open Login Items Settings and approve the bundled helper.

The helper opens AlphaSync when a Neo appears. It does not read keyboard input or transfer files itself. Disable automatic opening in Settings if you no longer want it.

A failed app opening gets up to three attempts. Connection monitoring retries temporary failures in short bursts with a pause between them. Both the app and helper restart monitoring when your Mac wakes. If a connection still fails, use Try Again or Refresh in AlphaSync.

Keep the helper inside the app. If an old AlphaSync installation starts a separate helper from Application Support, disable that old automatic-opening setting before replacing the app.
