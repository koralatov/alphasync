AlphaSync Help

Choose a text format your Neo can store

AlphaSync imports plain text into AlphaWord and the user dictionary. A word-processing document may need to be saved as plain text first.

Choose a supported format

Imports accept UTF-8, UTF-16 with a byte-order mark in either byte order, and MacASCII (Mac Roman). A byte-order mark is an encoding marker at the start of a text file. UTF-8 is usually the simplest choice when saving new text on your Mac.

Copies and backups made by AlphaSync use UTF-8 text, without a byte-order mark, for AlphaWord and dictionary files. Paragraph endings from Windows, older Macs, and Unix are converted consistently.

Resolve an unsupported character

The Neo stores fewer characters than your Mac. Supported accents, pound signs, and curly quotes can be preserved, but many emoji and mathematical symbols cannot.

If AlphaSync names an unsupported character, edit the source text to remove or replace it and import again. The app stops rather than silently changing an unsupported character.

Make text fit

The Neo’s limit applies after conversion, so the size shown in Finder may differ from its size on the Neo. Shorten or split oversized text. If memory is low, save a backup before clearing writing you no longer need.

An unreadable file limit blocks writing. Reconnect the Neo and refresh before trying again. Names must use 1 to 15 supported characters.

Prepare dictionary words

Use words of 2 to 20 supported characters, separated by spaces or line breaks. AlphaSync reports unusable words before you choose whether to continue. A non-empty source with no usable words is rejected. Use Clear File… when you intend to empty a dictionary.

Keep other applet data

Other applet files can be exported and backed up as .xml files that preserve the original data. AlphaSync cannot import or change those formats in this version. Raw .neo recovery files are also not text imports.
