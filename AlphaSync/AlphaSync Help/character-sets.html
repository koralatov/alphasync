Character Set Issues

AlphaSync writes exported files and backups in UTF-8. This preserves the accented letters, punctuation, and currency symbols supplied by the Neo. An encoding preference saved by an older version does not change the output format.

Imports accept MacASCII (Mac Roman), UTF-8, and UTF-16, including either UTF-16 byte order with a byte-order mark. AlphaSync detects the input encoding when it opens the file.

The Neo has its own supported character set. If an imported file contains characters that the device cannot store, AlphaSync reports the problem before replacing the device file.
