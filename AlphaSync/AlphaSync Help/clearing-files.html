Clearing files

Clearing removes the selected text on your Neo and cannot be undone.

  1. Select one file for Clear File…, or several files in the same applet for Clear Selected Files….
  2. To clear an entire applet, choose it in the sidebar and clear the file selection. The command becomes Clear All Files….
  3. Read the warning and check the named files before proceeding.

Cancel is the default and has initial keyboard focus. Return or Space should cancel when the warning first opens. Tab can deliberately move focus to other controls.

Save a recovery copy first is on by default. Each original is saved as readable text and raw Neo data before clearing starts. If the requested copy cannot be completed, no clearing starts. Use Open Recovery Copies in Settings to find the originals.

Clearing is available for AlphaWord and user dictionary files. It is unavailable for other formats and during another operation. Changed files are read back to verify them. A failure after clearing starts can leave some files changed; the error includes the recovery location when a copy was saved.

Quit stops the read-only preparation for clearing, including the final check of the originals. Once clearing starts writing, all writes and read-back verification in that change finish before AlphaSync closes.
