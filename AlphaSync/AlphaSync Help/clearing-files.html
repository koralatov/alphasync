Clearing Files



Clearing a single file


To clear a file’s contents, select it in the main window and click Clear File…. Read the warning, then choose Clear File to clear the file or Cancel to keep it. Cancel is the default.


Clearing all AlphaWord files


To clear all AlphaWord files, select AlphaWord in the main window and click Clear All Files…. The warning names the applet whose files will be cleared. Click Clear All Files to proceed. Cancel is the default.

Keeping the original text

Save a recovery copy first is on by default. AlphaSync saves the original text inside Recovery Copies in your backup folder. If that copy cannot be completed, clearing stops. Preferences controls how long copies are kept and provides an Open Recovery Copies button.

Clearing cannot be undone with the Edit menu. To restore saved text, drag the recovery text file onto the matching file in AlphaSync. Keep separate backups of important files.

AlphaSync reads the contents back after clearing. If it cannot confirm the result, it explains that some contents may have changed. Check the Neo and your recovery copy before continuing.
