Clearing Files



Clearing a single file


To clear a file’s contents, select it in the main window and click Clear File…. Read the warning, then choose OK to clear the file or Cancel to keep it. Cancel is the default.


Clearing all AlphaWord files


To clear all AlphaWord files, select AlphaWord in the main window and click Clear All Files…. The warning names the applet whose files will be cleared. Cancel is the default.

Clearing cannot be undone. Back up your files before clearing them.
