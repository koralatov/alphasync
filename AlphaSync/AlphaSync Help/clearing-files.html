Clear files on your Neo

Before clearing: save a backup of important writing. Clearing removes the selected text on your Neo and cannot be undone with Edit → Undo.

Choose what to clear

  • For one file, select it and choose File → Clear File….
  • For several files in the same applet, select them and choose File → Clear Selected Files….
  • For every file in one applet, choose that applet in the sidebar, clear the file selection, and choose File → Clear All Files….

The toolbar’s clear button performs the same action. You can also Control-click selected files to use their Clear command. Clear All Files applies to the selected applet, not every applet or every connected Neo.

Review the warning

  1. Check the named files.
  2. Keep Save a recovery copy first selected to save their originals. If that copy fails, clearing stops.
  3. Choose the named Clear button to proceed, or Cancel to keep the contents.

Cancel is the default and has the initial keyboard focus. Keep the Neo connected while clearing and verification finish. If a failure occurs after writing starts, some files may already have changed; read the message and check the recovery location.

Clearing is available for AlphaWord and user dictionary files. If it is unavailable, choose supported files from one applet and wait for any active operation to finish. Selecting All Files without a file selection does not choose an applet to clear.
