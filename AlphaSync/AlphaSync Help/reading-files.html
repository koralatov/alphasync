Read and find text in a file

Read a file in its own window without changing the writing on your Neo.

  1. Select a file in the main list.
  2. Choose File → Open Read-only, or double-click the file. Select several files before choosing the command to open them in separate windows.

Find text

Click in the file’s text, then choose Edit → Find → Find…. Use Find Next or Find Previous to move between matches. To search for selected text, choose Use Selection for Find.

Copy text

Choose Copy to Clipboard to copy the complete loaded file, including text below the visible area. To copy only part of it, select that text and choose Edit → Copy. The clipboard button is unavailable while loading, after a failed read, or when the file is empty.

Choose a font

Choose Regular or Monospaced at the top of the window. The choice is remembered for new reader windows. It changes how you read the text, not the file on your Neo.

Read later changes

Loaded text stays available if you disconnect the Neo. It is a snapshot, so it does not follow later changes. Close the reader, refresh the main file list, and open the file again to read an updated copy.

If reading fails while the same Neo remains connected, choose Try Again. After disconnecting and reconnecting it, refresh the main list and open the file in a new reader window. Closing the window cancels a read or retry that is still loading. To edit the writing on your Mac, save a text file, edit it in a plain-text editor, then import it back.
