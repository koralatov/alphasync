Move between controls

Use Tab and Shift-Tab to move between controls. If Tab does not reach every control, turn on Keyboard navigation in System Settings.

Clear, Replace, and dictionary-import warnings initially focus Cancel. Return or Escape cancels; Space activates the focused button. Move focus deliberately before confirming a change.

During a backup, Escape activates Stop while the backup has the keyboard focus. In a reader, click in the text before using the Find shortcuts.
