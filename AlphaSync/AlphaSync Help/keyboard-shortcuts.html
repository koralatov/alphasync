Keyboard shortcuts

  • ⌘O: open selected files read-only.
  • ⇧⌘I: import text files to the Neo.
  • ⇧⌘S: save files to your Mac.
  • ⌘I: show Inspector.
  • ⌘R: refresh the Neo file list.
  • ⌘,: open Settings.
  • ⌘?: open AlphaSync Help.
  • ⌘C and ⌘A: copy and select all text in a read-only window.
  • ⌘F, ⌘G, ⇧⌘G, and ⌘E: Find, Find Next, Find Previous, and Use Selection for Find.

Clear and Replace warnings initially focus Cancel. Return is the Cancel default; Escape also cancels. Tab and Shift-Tab move between controls when macOS keyboard navigation is enabled.
