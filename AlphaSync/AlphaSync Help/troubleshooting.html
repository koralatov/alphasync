AlphaSync Help

Solve a connection or file problem

Your Neo or its files do not appear

  1. Check that the Neo is connected with a working USB cable. If you use an adapter or hub, check its connection too.
  2. Close other Neo file-transfer software that may be using the device.
  3. Read the message in AlphaSync, then choose Try Again or View → Refresh Neo Files.
  4. If no transfer is active, disconnect and reconnect the Neo, then try again.

If macOS asks for accessory approval, review the prompt for your Neo. After sleep, use Refresh if the connection has not returned. If only one Neo fails, its warning can remain above the working Neo’s file list.

If only some files are missing, choose the correct Neo and applet in the sidebar and check Settings → Show. The filter may hide other applets.

A command is unavailable

Wait for the current transfer or confirmation to finish. Import, Rename, and Clear work with AlphaWord and user dictionary files. Adding text needs an applet and no file selection; replacing needs exactly one selected file. Clearing several files needs one applet. To clear an entire applet, select the applet itself and clear the file selection.

A backup or recovery folder is missing

Open AlphaSync → Settings… and check Save to. Reconnect the destination drive or choose the folder again. The default backup folder is created on first use; the Recovery Copies folder is created when first needed. A failed saved destination is not silently recreated elsewhere.

A copy or backup stopped

Read the saved count, folder locations, and errors. Files already saved are kept. A backup folder marked (Incomplete) may contain only some of the expected files. Keep those copies, resolve the problem, and start a fresh backup.

An import was rejected

Use plain text and check the message for unsupported characters, file-name length, size, memory, or dictionary-word limits. Shorten or correct the source, then import again. If a batch added some files before stopping, check the Neo before repeating it.

A change or verification failed

Writing may already have changed the file. Keep the saved recovery copies, reconnect and refresh, and read the current file before trying another change. A file changed after its warning opened needs a new review.

You need to stop or quit

During a backup, choose Stop. Close a reader to stop a read that is still loading. Quitting stops read-only preparation, but writing that has already begun finishes and is checked before AlphaSync closes. Keep the Neo connected while it finishes.

If the problem continues, report the exact message and the steps that led to it.
