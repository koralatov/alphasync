Rename a file on your Neo

Rename an AlphaWord or user dictionary file from its shortcut menu.

  1. Select the file in the main list.
  2. Control-click its name and choose Rename….
  3. Enter a name using 1 to 15 supported characters.
  4. Choose Rename, or Cancel to keep the old name.

Renaming changes the name, not the file’s writing. It does not assign the file to a different Neo file key.

If Rename is unavailable, select exactly one file in a supported applet and wait for any active operation to finish. Other applet formats are read-only. AlphaSync rejects unsupported or overlong names rather than shortening them silently.
