Preferences

Open Preferences from the AlphaSync menu. Changes are saved automatically.

Files

Use Show to choose which files appear in the main window. Quick Backup includes only the files shown there.

Exported files and backups always use UTF-8, preserving accented letters, currency symbols, and other characters supplied by the NEO. Preferences shows this as a fixed format.

Imports still accept MacASCII (Mac Roman), UTF-8, and UTF-16. The input encoding is detected when a file is opened, independently of the export format.

Backups

The folder path shows where Quick Backup saves your files. Click Choose… to pick a different folder. Cancelling the chooser keeps the current folder.

Save a backup log is off by default. Enable it if you want a record of copied files and any errors. Each log is saved as AlphaSync Backup Log.plist inside the dated backup folder. Changing this option affects the next backup.

Automatic opening

Select Open AlphaSync when a NEO is connected to open the app automatically when you plug in your NEO.

The message below the tick box shows the current system status. On macOS 13 and later, use Open Login Items Settings if macOS needs your approval.
