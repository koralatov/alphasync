AlphaSync Help

Change AlphaSync settings

Choose AlphaSync → Settings…. Changes are saved as you make them.

Choose files to show and back up

Under Files shown and backed up, the Show menu offers AlphaWord files, AlphaWord and dictionary files, or All applet files. The default includes AlphaWord and dictionary files. The filter changes the main list and backup contents; it does not remove device files.

Choose a backup folder

Under Backups, click Choose… beside Save to and select a folder. Backups and recovery copies both use this destination. The default is Documents → AlphaSync.

The default folder is created when first used. Remembered destinations follow moves and renames. If a folder is missing, reconnect its drive or choose it again. Backups and requested recovery copies stop until a valid destination is available.

Save a backup log is off by default. Enable it to keep a result log inside each dated backup folder.

Keep recovery copies

Save recovery copies by default is on initially. A Replace or Clear warning can change that choice for that operation without changing this setting. Keep copies defaults to 30 days. Choose Open Recovery Copies to find saved originals.

Open automatically

Open AlphaSync when a Neo is connected records your choice. Read the status below it to see whether macOS has enabled the helper or still needs Login Items approval. Open Login Items Settings opens the relevant system settings.

Choose an appearance or reading font

AlphaSync follows your Mac’s Light or Dark appearance. The reading font is chosen in each file’s read-only window with Regular or Monospaced; its last choice is remembered for new reader windows.
