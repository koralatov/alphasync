AlphaSync Help

Back up your Neo files

A backup saves a dated copy of the included files from every connected Neo. Selecting one file, applet, or Neo does not limit the backup.

Choose what to back up

  1. Choose AlphaSync → Settings….
  2. Under Files shown and backed up, use Show to choose AlphaWord files, AlphaWord and dictionary files, or all applet files.
  3. Under Backups, use Choose… beside Save to to choose a destination if needed. The default is the AlphaSync folder in Documents.

The same filter controls the main file list and backup contents. To save only selected files, use Save to Mac… instead.

Make a backup

  1. Connect the Neos you want to back up.
  2. Click Backup, or choose File → Back Up Neo Files.
  3. Wait for the result. Check the saved and expected file counts and any errors.
  4. Choose Open Backup Folder or Open Backup Folders to see the copies in Finder, then choose Done.

Each Neo gets its own dated folder, with files grouped by applet. Repeating a backup preserves earlier copies. AlphaWord and dictionary copies use .txt; other applet data uses .xml and cannot be restored through AlphaSync in this version.

Stop or check an unfinished backup

Choose Stop to end a backup. Files already saved stay on your Mac. A folder keeps (Incomplete) in its name until all its included files finish successfully. An unfinished folder is not a complete backup, even if some files are present.

Read the result before trying again. A fully saved first Neo can remain complete if another Neo fails. If there are no included files, the result says so.

Save a backup log

Logs are off by default. Enable Save a backup log in Settings to include an AlphaSync Backup Log.plist inside each dated folder. It records which files were saved and any errors; your writing remains in the separate files.
