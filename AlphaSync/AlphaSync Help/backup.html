Backing up files

Click Backup to save the files included by the file filter in Settings. Each Neo has its own dated destination inside the selected backup folder.

Backups use UTF-8 text for AlphaWord and dictionary files. Other applet files are saved as lossless XML.

The destination starts with (Incomplete) in its name. This is removed only when that Neo’s files finish successfully. Existing backups are preserved. If the complete file list cannot be read, AlphaSync stops before treating a partial list as a complete backup.

Stop and Quit can interrupt a backup between blocks of the file being read. Files already saved remain in the unfinished folder. If a file fails, the result explains what was saved and lists any folders that were created. Open Backup Folder shows the saved files in Finder. Done dismisses the result.

Backup logs are off by default. Enable Save a backup log in Settings if you need one. AlphaSync Backup Log.plist stays inside the dated folder and records relative paths, errors, and the final state.

The default backup folder is created and remembered when first used. Selected and default destinations follow moves and renames. If a saved destination is missing, reconnect its drive or choose it again in Settings. AlphaSync does not recreate its old path.
