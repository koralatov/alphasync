Quick Backup

To back up all files for all currently connected devices, click Backup in the toolbar or press Command-B. All files that are accessible in the main window will be backed up, even if they are not selected.

Backups are saved in the AlphaSync folder in Documents by default. The backup location can be changed in the preference settings.

Each Neo’s files are saved in a dated folder. Backup logs are off by default. To save a record of copied files and any errors, enable Save a backup log in Preferences. The log is saved inside that dated folder as AlphaSync Backup Log.plist.

Each dated folder ends in (Incomplete) while its files are being copied. AlphaSync removes this label only when that Neo’s backup finishes successfully. A stopped, interrupted, or failed backup keeps the label, even when logs are off.

The result shows the saved location. Use Open Backup Folder to open it in Finder. With more than one Neo, use Open Backup Folders to open their locations.

The general backup location can also be opened in Finder from the AlphaSync File menu or by pressing Command-R
