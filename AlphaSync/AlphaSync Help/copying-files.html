AlphaSync Help

Copy files to your Mac

Save a copy of your writing on your Mac. The original files stay on your Neo.

  1. Choose your Neo or an applet in the sidebar.
  2. Select the files you want to copy. With no files selected, Save to Mac… copies every file in the current list.
  3. Choose File → Save to Mac…, choose a destination folder, and confirm the folder choice.
  4. Read the result to check how many files were saved and where.

Drag a file into Finder

You can also drag a file’s name from the list into a Finder folder. Keep the Neo connected until the copy finishes.

Find the saved copy

AlphaWord and dictionary files are saved as UTF-8 .txt files. Other applet files are saved as .xml data, which AlphaSync can preserve but cannot import back in this version.

If a file with the same name already exists in the destination, AlphaSync gives the new copy a different name. Existing Mac files are preserved.

If copying stops

A saved file is kept even if a later file fails. Read the message for the saved count and location, then check the destination before trying again.
