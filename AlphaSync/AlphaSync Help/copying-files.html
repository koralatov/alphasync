AlphaSync Help

Reading and copying files

Read a file

Double-click a file to open its own read-only window. Choose Regular or Monospaced to use the system font and size. Use Edit → Find to search, or select text and use Edit → Copy.

Copy to Clipboard copies all the loaded text without changing its selection. The text stays available after you disconnect the Neo. Close and reopen the window after refreshing to see later changes.

Save to your Mac

Select files and choose File → Save to Mac…, then choose a folder. You can also drag file names into a Finder folder. Existing files are preserved, with a numbered name used for another copy.

Add or replace text

Choose AlphaWord or the user dictionary in the sidebar. With no files selected, choose File → Import Text Files to Neo… to add text. Select one file before importing to replace that file, or drop a text file onto its name.

New AlphaWord files are unbound. Use the Neo’s Open command to find them. Names must fit the Neo’s 15-character limit and use supported characters.

A replacement requires confirmation. Cancel has the initial keyboard focus and is the default. Save a recovery copy first is on by default. If that copy fails, the replacement stops.

Use plain text in MacASCII (Mac Roman), UTF-8, or UTF-16 with a byte-order mark. Unsupported characters, unreadable limits, insufficient memory, and text above the converted-size limit stop the change. AlphaSync reads changed contents back to verify them. If writing or verification fails, the file may already have changed; check your recovery copy.

Other applet formats can be exported and backed up as XML, but cannot be imported or changed in this version.
