Copying Files

Reading a File

Double-click a file in AlphaSync to open it in a separate read-only window. You can resize the window, scroll through the complete file, and select text to copy it.

Use Edit → Select All and Edit → Copy to copy text. Use Edit → Find → Find… to show the standard search bar. These commands leave the Neo’s file unchanged.

Use Font to choose Regular or Monospaced. Both use the system font and default size. AlphaSync remembers your choice for new windows.

The opened text remains available if you disconnect the Neo. To view later changes made on the Neo, close the file window, refresh AlphaSync’s file list, and open the file again.

Copying Files from a Neo to a Mac

Drag a file from AlphaSync to a Finder folder to save a complete copy on your Mac. To copy text into another app, open the file in AlphaSync, select the text, and use Copy and Paste.

Dragging a device or applet name to Finder creates a new folder containing its files.

Copying Files from a Mac to the Neo

To copy a file to the Neo, drag the file from the Finder to the AlphaSync main window.

Dragging a file to an Applet icon will attempt to create a new file with a suitable name. These are not directly bound to one of the File keys on the Neo, but must be opened. When using AlphaWord, type cmd-O to open a file copied in this way.

Dragging onto an existing file shows a warning before replacing its text. Cancel is the default. Click Replace to proceed.

Save a recovery copy first is on by default. It saves the original text in Recovery Copies inside your backup folder. If the requested copy cannot be completed, the replacement stops. You can find the originals and choose how long to keep them in Preferences.

Only plain text files may be copied to AlphaWord or to the User Dictionary. AlphaSync accepts MacASCII (Mac Roman), UTF-8, and UTF-16. To copy a document from Microsoft Word or another word processor, first save it as plain text with a .txt extension.

AlphaSync checks the file’s size in the Neo’s format before adding or replacing a file. If it exceeds the maximum file size or the available memory, the warning explains the limit. Shorten the text or split it into smaller files, then try again. Rejected imports leave your Neo’s files unchanged.

If AlphaSync cannot read the file-size limit or available memory, it stops the import. Disconnect and reconnect the Neo, then try again.

After sending a file, AlphaSync reads it back to check the contents. If verification fails, the warning explains that the Neo’s file may have changed. Check the file and your recovery copy before continuing.
