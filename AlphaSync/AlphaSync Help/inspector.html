The File Inspector

The file inspector shows more detail about a device, file or applet than is shown in the main window.

To open the inspector window, click the Info toolbar icon. The inspector will show information about the currently selected file.

The Inspector has two sections that stay open. Preview shows the file’s text or the selected item’s icon. You can scroll through a long text preview and select text to copy it.

More Info shows labelled details for the selected file, applet, or Neo. The window adjusts to fit those details. Selecting several items clears the individual details.

Sizes use bytes and KB, as in Finder. The detailed view shows exact byte counts with thousands separators, such as 51,200 bytes. Numbers follow your Mac’s regional settings.

A text preview may be unavailable while the Neo’s file contents are still being read.
