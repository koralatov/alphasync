Inspect a file, applet, or Neo

Use the Inspector to check the selected item’s details and see the beginning of a file.

  1. Select one file, an applet, or All Files beneath a Neo in the sidebar. Clear any file selection to inspect an applet or the Neo itself.
  2. Click Info, or choose View → Show Inspector.

Read More Information

A file’s details include its size, memory use, file-key assignment, and any password information supplied by the Neo. Unbound means it is not assigned to a file key such as F1. These details are selectable for copying.

For an applet, you can see its version, file count, size limits, and memory use. For the Neo, you can see its system version and available memory. RAM and ROM are the memory labels reported by the device.

Unavailable means AlphaSync could not obtain a limit; it does not mean that there is no limit. The Neo does not provide a reliable last-modified date for each file.

Read the preview

Preview shows a short extract from one selected file. It refreshes when the selection or file contents change through AlphaSync. After changes made on the Neo itself, use View → Refresh Neo Files. To read, search, or copy the complete file, open its separate read-only window.
