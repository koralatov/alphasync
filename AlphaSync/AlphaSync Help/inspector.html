Using the Inspector

Select a file or applet, then click Info or choose View → Show Inspector. You can also inspect a Neo by choosing All Files in its sidebar section without selecting a file.

More Information and Preview stay open. More Information shows the selected item’s details, using grouped exact byte counts. Preview shows a read-only extract for one file or an icon for an applet.

An unavailable limit is shown as Unavailable. It does not mean the Neo can accept an unlimited file. The Neo does not provide a reliable last-modified timestamp for each file.
