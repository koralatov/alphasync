AlphaSync Help

Get help or report a problem

Choose Help → AlphaSync Help or press ⌘? for this guide. You can use these pages without an internet connection.

Check your installed version

Choose AlphaSync → About AlphaSync to see the version, build, and edition. Help → Release Notes for 2.0.5 opens notes for that installed version online. Help → Licence opens the original licence and copyright notice offline.

Report a problem

  1. Read the relevant troubleshooting topic and note the exact error message.
  2. Choose Help → Report an Issue… to open the GitHub report form, or Help → Contact Us… to prepare an email in your usual mail app.
  3. Describe what you were trying to do, what happened, and what you expected. Include the Neo model and whether the problem followed a connection, sleep, or file change if that helps explain it.
  4. Review the report or email before sending it yourself.

The initial form includes only the app version, build, edition, macOS version, and Mac architecture. AlphaSync does not attach your writing, paths, device identifiers, or files. Review anything you add and remove private writing or password information you do not want to share.

Help → AlphaSync on GitHub opens the project online. GitHub reports and release notes need internet access. Sending email also depends on your mail app and connection.

If a link cannot open

Check your usual browser or mail app. If AlphaSync offers Copy Link, use it to copy the address and open it yourself.
