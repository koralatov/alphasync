## What changed since 1.4.2

- The Clear button now says **Clear File…** when a file is selected and **Clear All Files…** when an applet is selected.  Its tooltip names the target.  Clearing remains available only for AlphaWord files.
- **Cancel** is now the default in both Clear warnings.  Only choosing **OK** permits clearing.
- Without a NEO connected, AlphaSync shows a smaller **No NEO connected** window with a native cable icon and connection instructions.  The same window expands to the file viewer when a NEO connects and shrinks after the last one disconnects.
- The file viewer starts at a narrower width and remembers its chosen size when a NEO reconnects.  An open backup result or file dialogue can finish before the window shrinks.
- File sizes use Finder-style **KB** and **bytes**.  The file list and Inspector show the same size.
- The macOS 27 Apple Silicon app uses the preferred glass icon.  The Universal app keeps the original green icon.

The new connection window follows your Mac’s Light and Dark appearance automatically.  Exports and backups use UTF-8, and imports accept MacASCII (Mac Roman), UTF-8, and UTF-16.

## Install and open

Unpack the ZIP, move **AlphaSync** to **Applications**, and open it.  Replace an older copy rather than installing both versions together.  If macOS blocks the first launch, follow the [installation and opening instructions](https://github.com/koralatov/alphasync/blob/v1.4.3/README.md).

## Testing

Automated checks cover both compiled apps, text conversion, file saving, backup reports, background tasks, native windows, Clear-warning defaults and response handling, and changes between Light and Dark Mode.  Both downloads use the pinned release compilers.

Real NEO transfers, automatic-launch approval, and runtime behaviour on macOS 11 and 12 still need manual testing.  Back up your NEO’s files before testing transfers or clearing files.  This release remains marked as a prerelease while those checks are outstanding.  The [technical guide](https://github.com/koralatov/alphasync/blob/v1.4.3/TECHNICAL.md) explains the checks in more detail.
