## What changed since 1.4.1

- Preferences now groups file settings, backups, and automatic opening in a standard Mac window.  The backup folder is easier to see and change, and longer status messages fit properly.
- About shows the app’s version, build number, and supported macOS versions, along with credits and links to the project, release notes, and licence.
- The backup completion dialogue explains how many files were saved and shows the actual dated backup folder.  **Open Backup Folder** opens that location in Finder, and **Done** closes the dialogue.
- When backing up more than one NEO, the dialogue lists each backup folder and can open them all.  Long paths wrap and can be selected for copying.
- Incomplete and stopped backups explain how many files were saved, failed, or were not copied.  Empty backups have their own message.
- The updated windows use native Mac controls, fit their content, and follow Light and Dark Mode.

Exports and backups continue to use UTF-8.  Imports still accept MacASCII (Mac Roman), UTF-8, and UTF-16.

## Install and open

Unpack the ZIP, move **AlphaSync** to **Applications**, and open it.  Replace an older copy rather than installing both versions together.  If macOS blocks the first launch, follow the [installation and opening instructions](https://github.com/koralatov/alphasync/blob/v1.4.2/README.md).

## Testing

Automated checks cover the compiled apps, text conversion, file saving, backup reports, background tasks, native windows, and changes between Light and Dark Mode.  The release downloads use the pinned compilers for macOS 26 and macOS 27.

Real NEO transfers, automatic-launch approval, and runtime behaviour on macOS 11 and 12 still need manual testing.  Back up your NEO’s files before testing transfers.  This release remains marked as a prerelease while those checks are outstanding.
