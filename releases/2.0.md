# AlphaSync 2.0

AlphaSync is a free Mac app for reading, copying, and backing up files from an **AlphaSmart Neo** writing device. Connect your Neo with a USB cable to read your writing on your Mac, save a copy, or send text back to the Neo.

**Version 2.0, build 149, requires macOS 13 Ventura or later.** There are downloads for Intel and Apple Silicon Macs. For macOS 11 Big Sur or macOS 12 Monterey, use [AlphaSync 1.5.1](https://github.com/koralatov/alphasync/releases/tag/v1.5.1).

AlphaSync was originally written by tSoniq. Version 2.0 is the first public release of a complete Swift rewrite. The new version number marks that change from 1.5.1 and the earlier Objective-C and Objective-C++ versions. The main purpose stays the same: getting your writing safely between your Neo and your Mac.

## What it does

- **Read your Neo’s files.** Open a file in a separate, read-only window, search its text, and copy the complete text to the clipboard.
- **Copy files in either direction.** Save files through the File menu or by dragging them into Finder. Import text files, or drop one onto a file to replace its contents after confirmation.
- **Back up your writing.** Save the included files in dated folders, with a result that shows what finished and where it was saved.
- **Keep recovery copies.** Before replacing or clearing a file, save its original text and original Neo data. If a requested recovery copy fails, the change stops.
- **Open automatically.** Enable automatic opening in Settings to start AlphaSync when you connect a Neo.

## What is different from 1.5.1

The app has been rebuilt with Apple’s current Mac tools. It has a sidebar for choosing a Neo or one of its applets, a file table, native Settings, and separate windows for reading and file information. It follows your Mac’s Light or Dark appearance.

Recovery copies now include the original Neo data as well as readable text. File previews refresh after changes. Imports and exports keep their original targets while a file chooser is open, and interrupted exports explain which files were saved. Failed connections wait for Refresh or Try Again instead of repeatedly retrying in the background.

The minimum system has changed to macOS 13. Both downloads offer the same features. The Apple Silicon edition contains only the code needed for an M-series Mac and uses the newer icon; the Universal edition also includes Intel code and uses the original icon.

AlphaWord and user dictionary files can be imported and changed. Other applet files can be read, exported, and backed up as XML, but cannot be imported or changed by this version.

Install one edition. Each ZIP contains **AlphaSync.app** and its bundled automatic-launch helper. The separate **symbols** ZIPs are for developers investigating crashes.

## How to install it

1. Double-click the downloaded ZIP file to unpack it.
2. Quit an older copy of AlphaSync if it is running.
3. Drag **AlphaSync** into your **Applications** folder. Replace the older copy if Finder asks.
4. Open **Applications**, then double-click **AlphaSync**.

These downloads are not Apple-notarised. If macOS blocks the first opening, follow [Apple’s instructions for opening a downloaded app](https://support.apple.com/en-gb/102445). The approval is in **System Settings → Privacy & Security**. Use it only for the copy you downloaded from this release page.

If you used automatic opening in an older version, check it again in **AlphaSync → Settings…** after installing. Follow any Login Items approval prompt. Keep the app and its bundled helper together.

## How to use it

Open AlphaSync, then connect your Neo with a USB cable. Choose the Neo or applet in the sidebar. If a connection fails, review its message and choose **Try Again** or **Refresh**.

- **Read:** double-click a file. Choose Regular or Monospaced, use **Copy to Clipboard**, or search with **Edit → Find**.
- **Save to your Mac:** select files and choose **File → Save to Mac…**, or drag their names into a Finder folder. Existing Mac files are kept, and another copy gets a different name.
- **Add text to your Neo:** choose AlphaWord or the user dictionary, clear the file selection, then choose **File → Import Text Files to Neo…**.
- **Replace text:** select one file and import one text file, or drop a text file onto its name. Check the named target in the warning before continuing.
- **Back up:** click **Backup**. Choose the destination and optional backup log in **AlphaSync → Settings…**. An unfinished backup keeps **(Incomplete)** in its folder name.
- **Clear:** select files for **Clear File…** or **Clear Selected Files…**. With an applet selected and no files selected, **Clear All Files…** clears that applet’s files. **Cancel** is the default in every destructive warning.

**Save a recovery copy first** is enabled by default. In Settings, choose **Open Recovery Copies** to find the saved originals. Restore text by importing its saved `.txt` file onto the matching Neo file. Keep the accompanying `.neo` files for recovery or diagnosis; they are not text imports.

Recovery copies are kept for 30 days by default. Settings offers 7, 30, or 90 days, or no automatic expiry. Expired recognised copies move to Trash when a new copy is made. Keep a separate backup of important writing.

If a file is too large or contains a character your Neo cannot store, AlphaSync explains the problem and stops the import. Shorten or edit the text, then try again.

For the built-in guide, choose **Help → AlphaSync Help** or press **⌘?**.

## Technical information

### Rewrite and differences from 1.5.1

The shipping application, login helper, protocol engine, codecs, and file operations are Swift, with Swift 6 strict concurrency checking. SwiftUI provides the main interface. Small public AppKit adapters provide selectable read-only text, the native Find bar, Help, workspace operations, and orderly termination on macOS 13.

The rewrite was developed under version 1.6, which was not published. Version 2.0 is its first public release. The original BSD-style licence and tSoniq copyright notices remain. There are no third-party runtime libraries or separately installed USB drivers.

Both Xcode targets use the same Swift package. Universal contains x86_64 and arm64; Apple Silicon contains arm64 only. Both apps and their matching helpers have a 13.0 deployment target. The Silicon edition has a compile-time architecture guard, but no exclusive transfer features or unmeasured performance claims.

The shared modules are `AlphaSyncCore`, `AlphaSyncHardware`, and `AlphaSyncUI`. USB handles and mutable connection state stay on one serial executor. The main actor receives immutable `Sendable` snapshots. Connection generations prevent queued work from being redirected after reconnection.

The transport uses public IOUSBHost bulk APIs. Public HID output reports switch the Neo from its keyboard mode to its bulk-transfer mode. The helper reads attachment metadata only. It does not capture keyboard input, register a driver extension, or perform file transfers itself.

### File handling and fixes

- **Strict conversion:** exports and backups use UTF-8 without a byte-order mark, with LF line endings. Imports accept UTF-8, BOM-marked UTF-16 in either byte order, and MacASCII (Mac Roman). A declared UTF-8 file cannot silently fall back to Mac Roman after invalid bytes.
- **Validation before writing:** converted bytes must pass fresh applet limits and available-memory checks. Unsupported characters and names are rejected without replacement or truncation. Changed contents are read back for verification.
- **Recovery before changes:** requested copies preserve readable text, exact raw `.neo` bytes, and identification metadata before writing. A failed copy blocks the change. Recovery metadata is version 2; optional backup logs are version 3.
- **Original targets:** file chooser and drop requests capture their connection, applet, and file identities before asynchronous work. A lost original connection stops the request.
- **Current previews:** Inspector tasks include a content revision, so replacement, clearing, and explicit refresh invalidate cached text even when the file ID and allocation stay the same.
- **Structured failures:** device changes retain verified counts, possible unverified writes, underlying errors, and recovery locations. Export failures retain completed output URLs and the destination. Presentation does not infer outcomes by parsing English messages.
- **Controlled retries and cancellation:** failed connections and mode switches retain their errors until an explicit retry or detachment. Read-only work checks cancellation between blocks; an active write and its verification finish before shutdown. Transfer deadlines use `ContinuousClock`.
- **Local file protection:** exports use exclusive atomic publication and private permissions. Failed backups keep their incomplete marker. Drag exports advertise plain text or XML correctly. Staging keeps promised files available and removes recognised inactive sessions older than seven days, while locks protect active sessions.

### Differences from tSoniq’s latest release

[tSoniq’s latest published release is AlphaSync 1.3](https://github.com/tSoniq/alphasync/releases/tag/RELEASE_1_3). It already offered drag-and-drop transfers, backups, text conversion, and automatic opening. Version 2.0 keeps those core functions while replacing the earlier implementation, updating the native interface, adding current Mac architecture support, and carrying forward the file-protection work introduced in the 1.5 series.

### Install

The app embeds `Contents/Library/LoginItems/AlphaSyncLauncher.app`. Apps and helpers retain the identifiers `com.tsoniq.AlphaSync` and `com.tsoniq.AlphaSyncLauncher`, share version 2.0 and build 149, and use `SMAppService` for automatic opening on every supported system. Install one edition in Applications before enabling it. Disable a separately installed legacy helper before replacing an installation that uses one.

The release channel is `stable`, so About and Help link to the exact `v2.0` notes and licence. The preserved `v1.5.1` tag, `legacy-macos-11-12` branch, and their existing release assets remain separate.

The downloads have ad hoc code signatures, not Developer ID signatures or Apple notarisation tickets. Signature checks establish bundle integrity, not Apple approval or publisher identity. The build reports identify the signing state and exact source commit.

### Verification

Publication requires successful Intel and Apple Silicon build jobs, all 65 Swift regressions, packaging fixture checks, and native interface checks in Light and Dark appearances. Both native editions and their helpers are built and checked for exact architectures, macOS deployment targets, versions, bundle identifiers, selected icons, Help resources, hardened runtime, signatures, native dependencies, executable version output, and matching crash-symbol UUIDs.

The publication job downloads the resulting packages and checks all twelve assets again. It verifies SHA-256 hashes, source reports, archive contents, both extracted apps, and the extracted crash symbols before uploading a draft. Uploaded asset hashes must match before the draft becomes public. The build record linked below identifies the exact run.

Each app and symbols ZIP has a matching `.sha256` file and `.build-information.txt` report. Put the checksum beside its ZIP and run, for example:

```sh
shasum -a 256 -c AlphaSync-2.0-149-macOS-13-universal.zip.sha256
```

The result should end in **OK**. After installation, check bundle integrity with:

```sh
codesign --verify --deep --strict /Applications/AlphaSync.app
```

Source-level checks and build instructions are in the [technical guide at v2.0](https://github.com/koralatov/alphasync/blob/v2.0/TECHNICAL.md).

**Testing limits:** hosted builds and simulations do not establish physical Neo compatibility. Physical Neo transfers, Login Items approval on actual installations, and runtime checks on macOS 13 remain unverified for this release. An earlier development build was reported working on macOS 27, but that report does not identify individual transfer or helper checks. The [manual checklist at v2.0](https://github.com/koralatov/alphasync/blob/v2.0/tests/manual-checks.md) records the outstanding work.
