# AlphaSync 2.0 – archived release

Version 2.0, build 149 was the first public release of the Swift rewrite. It has been superseded by **[AlphaSync 2.0.2](2.0.2.md)** for macOS 13 and later. Use its release page for current downloads, installation, everyday use, and technical details.

The original [2.0 release notes](https://github.com/koralatov/alphasync/blob/v2.0/releases/2.0.md) and source remain at the preserved `v2.0` tag, commit `a508da036db4516d65d98b0a33e1d031e96f8b88`. The superseded release listing is retired after 2.0.2 is verified and published; its Git tag is retained.

For macOS 11 and 12, use **[AlphaSync 1.5.1](https://github.com/koralatov/alphasync/releases/tag/v1.5.1)**. Its source, legacy branch, and original downloads remain unchanged.
