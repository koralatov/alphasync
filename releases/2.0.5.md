# AlphaSync 2.0.5 – not released

AlphaSync copies and backs up text from an AlphaSmart Neo on a Mac. This test build requires macOS 13 or later and is prepared as version 2.0.5, build 155.

## Connection correction

A hardware report shows that 2.0.4 can leave a Neo in keyboard mode on an M2 MacBook Air, while 1.5.1 connects correctly on the same Mac.

This candidate restores the USB configuration and mode-switch command sequence used by 1.5.1, through the current public USB framework. It also detects the Neo directly as a USB device and shows a connection failure if the switch fails.

The correction still needs a physical Neo test. Successful compilation and simulated transfers do not confirm that the reported hardware problem is resolved. No public 2.0.5 download is available yet.

## Technical information

The [connection investigation](../docs/neo-keyboard-mode.md) records the hardware report, exact legacy control requests, scope, regression checks, and required physical tests. Both editions share this correction. File transfers, recovery copies, and the validated offline Help are retained.

Builds for both Intel and Apple Silicon, the full test suite, Help and package validation, and native interface checks are required before considering publication. Public releases, source tags, and existing downloads are not replaced by this candidate.
