# AlphaSync 2.0.5 – not released

AlphaSync copies and backs up text from an AlphaSmart Neo on a Mac.  This private test build requires macOS 13 or later and is ready for testing as version 2.0.5, build 167.

Build 164 tightens stopping and quitting before file changes and during connection checks.  It improves VoiceOver progress and status feedback, makes Find work with the active file, removes irrelevant right-click commands, and avoids repeated file-size formatter creation.  All earlier fixes are retained.

Build 163 shows the Inspector’s Preview section only when one file is selected.  A Neo or applet keeps its header icon and More Information, without a repeated enlarged icon.  Selecting several files also hides Preview.  File previews and all earlier corrections are retained.

Build 162 keeps the sidebar visible and removes Hide Sidebar, which was reported to freeze the previous test app.  You can still adjust its width.  Items are indented beneath their Neo, and a filled keyboard icon replaces the drive icon.  The clearer confirmations, applet icons, labelled toolbar choices, and earlier USB and performance corrections are retained.

## Connection correction

A hardware report shows that 2.0.4 can leave a Neo in keyboard mode on an M2 MacBook Air, while 1.5.1 connects correctly on the same Mac.

This candidate restores the USB configuration and mode-switch command sequence used by 1.5.1, through the current public USB framework. It also detects the Neo directly as a USB device and shows a connection failure if the switch fails.

On 15 November 2026, the user reported that the connection now works on the M2 Air. The screenshot confirms a connected file list, with a separate layout problem addressed in build 159. Real transfers, backup, and file changes still need their functional checks. No public 2.0.5 download is available yet.

The [connection investigation](../docs/neo-keyboard-mode.md) records the hardware report, exact legacy control requests, scope, regression checks, and required physical tests. Both editions share this correction. File transfers, recovery copies, and the validated offline Help are retained.
