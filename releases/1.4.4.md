## What changed since 1.4.3

- The Inspector now has a Finder-style layout using native macOS controls.  **Preview** and **More Info** stay open, with clear headings, separators, and aligned labels.  Detail values can be selected and copied, and long text wraps to fit.
- File previews can be scrolled and copied.  Selecting several items or clearing the selection removes the previous item’s details.
- File sizes consistently use Finder-style **bytes** and **KB**.  Exact byte counts use grouping separators, such as **51,200 bytes**, following your Mac’s regional settings.
- Backup logs are off by default.  To save one, enable **Save a backup log** in **Preferences**.  Each Neo’s dated backup folder then contains **AlphaSync Backup Log.plist**, covering that device’s files.
- Oversized imports are rejected before any files on the Neo are created or changed.  The warning explains the limit and how to proceed.  AlphaSync also checks available memory and stops if it cannot read the information it needs.
- The app, Help, and documentation now use the correct **AlphaSmart Neo** name and **Neo** casing.

The interface follows your Mac’s Light and Dark appearance automatically.  Exports and backups use UTF-8, and imports accept MacASCII (Mac Roman), UTF-8, and UTF-16.

## Install and open

Unpack the ZIP, move **AlphaSync** to **Applications**, and open it.  Replace an older copy rather than installing both versions together.  If macOS blocks the first launch, follow the [installation and opening instructions](https://github.com/koralatov/alphasync/blob/v1.4.4/README.md).

## Testing

Automated checks cover both compiled apps, text conversion, file-size and memory limits, rejected imports, backup logs, background tasks, native windows, Inspector layouts, Clear-warning defaults and response handling, and changes between Light and Dark Mode.  Both downloads use the pinned release compilers.

Real Neo transfers, automatic-launch approval, and runtime behaviour on macOS 11 and 12 still need manual testing.  Back up your Neo’s files before testing transfers or clearing files.  This release remains marked as a prerelease while those checks are outstanding.  The [technical guide](https://github.com/koralatov/alphasync/blob/v1.4.4/TECHNICAL.md) explains the checks in more detail.
