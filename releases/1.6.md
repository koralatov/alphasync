# AlphaSync 1.6

Archived development notes, build 148. Version 1.6 was never published. The first release of the Swift rewrite is [AlphaSync 2.0](2.0.md).

AlphaSync now requires macOS 13 or later. Two editions share the same Swift code: Universal for Intel and Apple Silicon, and a dedicated arm64 edition for Apple Silicon. Version 1.5.1 remains available separately for macOS 11 and 12.

- Rebuilds the application and file engine in Swift, with bounded binary parsing and serial USB ownership behind async operations.
- Replaces the file manager and supporting windows with native SwiftUI layouts that follow system appearance.
- Uses public IOUSBHost bulk APIs and HID output reports for the Neo’s mode switch, without a separate driver extension or keyboard monitoring.
- Preserves safe Cancel defaults, strict import validation, fresh size and memory checks, and read-back verification.
- Saves readable and raw recovery copies before requested destructive changes, and preserves existing local files during exports and backups.
- Keeps read-only windows, system font choices, Copy to Clipboard, Find, Settings, Inspector, and offline Help.

Other applet formats can be exported and backed up as lossless XML. Imports into those formats remain unavailable until they can be validated safely.

## Maintenance fixes

- Import and export choosers keep the files and Neo selected before they opened. Drops also keep their original target. Reconnecting a Neo cannot redirect an earlier request.
- Inspector previews reload after replacement, clearing, and Refresh, including changes that keep the same file number and size.
- Failed exports report how many files were saved and where. Completed files remain available, including when a later read is cancelled.
- Automatic error recovery refreshes file information without retrying failed USB connections. Refresh, Try Again, or physical reconnection allows another attempt.
- Drag exports advertise plain text or XML to match their contents. Private staging keeps promised files available and cleans recognised inactive sessions after seven days.

The [maintenance completion checks](https://github.com/koralatov/alphasync/actions/runs/42705949112) passed on Intel and Apple Silicon for source `6d991b756f68968ac99a03cc7ab5a22ef4ce9b53`: 65 Swift regressions, five packaging fixture checks, and native interface checks. These checks compiled shared code and test executables without rebuilding either app download. The earlier development downloads do not include these source changes.

Physical Neo transfers and macOS 13 runtime checks remain required before a public release. Successful hosted builds and simulations do not establish hardware compatibility.
