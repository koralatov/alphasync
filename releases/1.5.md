## What changed since 1.4.5

- **Recovery copies before replacing or clearing text.** This is on by default. AlphaSync saves the original text inside **Recovery Copies** in your backup folder before starting the change. If the requested copy cannot be completed, the change stops. Preferences offers 7-, 30-, and 90-day retention, or keeping copies until you remove them. The default is 30 days; expired recognised copies move to Trash when a new copy is made. **Open Recovery Copies** helps you find saved originals to restore manually.
- **Safer native confirmation sheets.** Replace and Clear warnings are attached to the main window. **Cancel** is the default, and the other button explicitly says **Replace**, **Clear File**, or **Clear All Files**.
- **Verification after changes.** Files are read back after writing or clearing. If AlphaSync cannot verify the result, it explains that contents may already have changed and gives the recovery location when a copy was saved.
- **Recognisable incomplete backups.** Dated folders keep **(Incomplete)** until that Neo’s backup succeeds, including when optional logs are off. Log paths continue to work when a completed folder loses its marker.
- **Clearer rename failures and natural sorting.** Unsupported or overlong names are rejected, unsuccessful renames are reported, and names such as File 1, File 2, and File 10 use Finder-style ordering.
- **Standard Edit and Find commands.** Copy, Select All, and Find work through the native Edit menu. Read-only file windows use the standard find bar and stay read-only. Preferences uses native scrolling when its form needs more space than the screen allows.
- **Bounded imports and fewer unnecessary reads.** Large local files are rejected without loading an unbounded amount of text. Full Neo file contents are read when needed for viewing, copying, or backup rather than for every list refresh.
- **Stricter USB replies and smaller release builds.** Unexpected response codes and malformed version fields are rejected. Interface test fixtures, unused resources, and debugging symbols are kept out of the app downloads. Matching crash symbols remain available as separate build artifacts. Documentation-only edits skip the full Mac build matrix.

Current guides and interface text use one space after a full stop. Exports and backups remain UTF-8, and imports accept MacASCII (Mac Roman), UTF-8, and UTF-16. Both editions use native Mac components and follow the system appearance.

## Install and open

Unpack the ZIP, move **AlphaSync** into **Applications**, and open it. Replace an older copy rather than installing both editions. If macOS blocks the first launch, follow the [installation and opening instructions](https://github.com/koralatov/alphasync/blob/v1.5/README.md).

## Testing

Automated checks cover simulated transfers, import limits and encodings, rename and verification failures, recovery scheduling, backup completion markers and logs, native sheets, read-only windows, menus, layouts, and appearance changes. Build checks cover both editions, app and helper versions, architectures, deployment targets, dependencies, signatures, archives, and matching separate crash symbols.

Real Neo transfers, recovery restoration and expiry, automatic-launch approval, and runtime behaviour on macOS 11 and 12 still need manual testing. Keep independent known-good backups while testing. This release remains a prerelease while those hardware and older-system checks are outstanding. See the [technical guide](https://github.com/koralatov/alphasync/blob/v1.5/TECHNICAL.md) and [manual checklist](https://github.com/koralatov/alphasync/blob/v1.5/tests/manual-checks.md).
