This is a testing release of the modernised AlphaSync app, version **1.4.1, build 141**.

## Downloads

| Download | macOS | Mac |
|---|---|---|
| Universal | 11 through 26 | Intel or Apple Silicon |
| Modern | 27 and later | Apple Silicon |

Both downloads contain **AlphaSync.app** and its automatic-launch helper.  Choose the ZIP for your Mac.  The accompanying `.sha256` files let you check the downloads, and the build reports record their version and source revision.

## What changed

- Two Mac versions now come from the same source and share the same app version.
- Native Mac controls, system icons, and Help pages follow Light and Dark Mode, including changes while the app is running.
- Text exports and backups use UTF-8.  Imports still accept MacASCII (Mac Roman), UTF-8, and UTF-16.
- File transfers run in the background so the app stays responsive.  Disconnecting a NEO stops queued work from reaching a replacement connection.
- Safer file saving preserves existing exports, and backup reports distinguish completed, failed, cancelled, and interrupted backups.
- Preferences reports the automatic-launch state and provides access to the relevant Mac settings when approval is needed.
- The README now explains installation and everyday use in plain English, with a separate technical guide for advanced users.

## Install and open

Unpack the ZIP, move **AlphaSync** to **Applications**, and open it.  If macOS blocks the first launch, follow the [installation and opening instructions](https://github.com/koralatov/alphasync/blob/v1.4.1/README.md).  Replace an older copy rather than installing both versions together.

## Testing

The automated checks cover builds on Intel and Apple Silicon Macs, text conversion, file saving, backup reports, background tasks, and Light and Dark Mode.  The required release builds use the pinned compilers for macOS 26 and macOS 27.

Real NEO transfers, automatic-launch approval, and runtime behaviour on macOS 11 and 12 still need manual testing.  Back up your NEO’s files before testing transfers.  This release is marked as a prerelease while those checks remain outstanding.
