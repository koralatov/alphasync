# AlphaSync 1.5.1

AlphaSync is a free Mac app for copying and backing up files from an **AlphaSmart NEO** writing device. Connect your NEO with a USB cable to read its files on your Mac, copy text in either direction, or make a backup.

**Version 1.5.1, build 147, is for macOS 11 Big Sur and macOS 12 Monterey.** The same download works on Intel and Apple Silicon Macs. This is the final release for those two versions of macOS. You can check your version in **Apple menu → About This Mac**.

AlphaSync was originally written by tSoniq. This version continues that work with support for newer Macs and improvements to file handling and the interface.

## What it does

- **Read your NEO’s files.** Open a file in a separate, read-only window, search its text, and copy it to the clipboard.
- **Copy files in either direction.** Drag files between AlphaSync and Finder, including named files on your NEO.
- **Back up your writing.** Click **Backup** to save the included files in a dated folder on your Mac.
- **Keep recovery copies.** Before replacing or clearing a file, AlphaSync can save its original text so you can restore it later.
- **Open automatically.** Enable automatic opening in Preferences to start AlphaSync when you connect your NEO.

## How to install it

1. Double-click the downloaded ZIP file to unpack it.
2. Quit an older copy of AlphaSync if it is running.
3. Drag **AlphaSync** into your **Applications** folder. Replace the older copy if Finder asks.
4. Open **Applications**, then double-click **AlphaSync**.

If your Mac says that it cannot verify AlphaSync, dismiss the warning and open **System Preferences → Security & Privacy → General**. Find the message about AlphaSync, choose **Open Anyway**, and follow the prompts. Use this option only for the copy you downloaded from this release page. The [installation guide](https://github.com/koralatov/alphasync/blob/v1.5.1/README.md#if-your-mac-blocks-alphasync) has more detail.

## How to use it

Open AlphaSync, then connect your NEO with a USB cable. Its files appear in the main window.

- **Read:** double-click a file. Choose Regular or Monospaced for the text, and use **Copy to Clipboard** to copy the complete file.
- **Save to your Mac:** drag files from AlphaSync into a Finder folder.
- **Send text to your NEO:** drag a text file from Finder into AlphaSync. If a Replace warning appears, check the named file before continuing.
- **Back up:** click **Backup**. Choose the destination in **AlphaSync → Preferences…**. A folder marked **(Incomplete)** contains a backup that did not finish.
- **Clear:** select a file and choose **Clear File…**, or select AlphaWord and choose **Clear All Files…**. Check the warning before confirming. **Cancel** is the default.

**Save a recovery copy first** is enabled by default. In Preferences, choose **Open Recovery Copies** to find the saved originals. To restore one, drag its text file onto the matching file in AlphaSync. Recovery copies are kept for 30 days by default, and expired copies move to Trash when a new copy is made. Keep a separate backup of important writing.

If a file is too large or contains a character your NEO cannot store, AlphaSync explains the problem and stops the import. Shorten or edit the text, then try again.

For the built-in guide, choose **Help → AlphaSync Help** or press **⌘?**.

## Technical information

### Fixes since 1.5

- **Complete backup enumeration:** backups stop if an included applet or file list is incomplete, or its file count cannot be confirmed. A partial listing cannot be reported as a complete backup.
- **Safer confirmation sheets:** Replace, Clear File, and Clear All Files open with Cancel as the default button and initial keyboard target. The destructive action no longer receives initial focus.
- **Toolbar layout:** the default connected window is wider so Backup, Clear, and Info fit, including the longer Clear All Files label.
- **About:** links no longer receive initial focus. Compatibility text identifies macOS 11 and 12, and release-note and licence links stay tied to 1.5.1.
- **Read-only windows:** a native status symbol identifies read-only text. Copy to Clipboard copies the complete loaded text. The Regular and Monospaced font choices have equal widths and explanatory tooltips.

### Differences from tSoniq’s latest release

[tSoniq’s latest published release is AlphaSync 1.3](https://github.com/tSoniq/alphasync/releases/tag/RELEASE_1_3). It already provided drag-and-drop transfers, one-click backups, text conversion, and optional opening when a NEO was connected.

This fork adds or updates:

- **Platform support:** one Universal binary containing x86_64 and arm64 code, with an 11.0 deployment target in both the app and helper.
- **Native interface:** updated AppKit windows, Light and Dark appearance, read-only file windows, system fonts, Find, selectable Inspector details, and built-in Help.
- **Text handling:** UTF-8 exports and backups, plus MacASCII, UTF-8, and UTF-16 imports. Windows line endings are handled consistently, and unsupported NEO characters are rejected before writing.
- **Write protection:** fresh device limits and available memory are checked after conversion. Changed contents are read back for verification. Optional recovery copies are saved before destructive operations, and a failed requested copy blocks the change.
- **Backup reporting:** existing exports are preserved, unfinished folders retain an incomplete marker, and optional logs record each dated backup’s results.
- **Device work:** USB requests run on one background queue, with bounded parsing and explicit checks for malformed replies.

Version 1.5.1 uses Objective-C++, C++17, and native AppKit. It has no third-party runtime libraries or separately installed USB driver. The original copyright notices and BSD-style licence are retained. The Swift and SwiftUI migration belongs to the separate 1.6 development work.

### Install

The installable ZIP contains **AlphaSync.app**, including **Contents/Library/LoginItems/AlphaSyncLauncher.app**. Keep this bundle intact and install one copy in Applications before enabling automatic opening.

On macOS 11 and 12, automatic opening uses `SMLoginItemSetEnabled`. If an older installation uses a separate helper in Application Support, disable that installation’s automatic opening before replacing it.

The exact release source is preserved at [v1.5.1](https://github.com/koralatov/alphasync/tree/v1.5.1) and [legacy-macos-11-12](https://github.com/koralatov/alphasync/tree/legacy-macos-11-12). The release assets and source references stay fixed. These revised notes do not change the app or its source at that tag.

To build the preserved source, use its shared **AlphaSync** scheme and the Xcode version pinned in `.xcode-version`. Build commands and implementation details are in the [1.5.1 technical guide](https://github.com/koralatov/alphasync/blob/v1.5.1/TECHNICAL.md).

### Verification

The [1.5.1 release checks](https://github.com/koralatov/alphasync/actions/runs/42611716983) passed on Intel and Apple Silicon build hosts. They cover core and native regressions, sanitizers, Debug and Release builds, app and helper architectures, macOS deployment targets, signatures, dependencies, archive layout, matching crash symbols, menus, layouts, and appearance changes.

The release includes SHA-256 checksums and build reports for the app and its separate crash symbols. Download the [app checksum](https://github.com/koralatov/alphasync/releases/download/v1.5.1/AlphaSync-1.5.1-147-macOS-11-12-universal.zip.sha256), put it beside the app ZIP, and run this command from that folder:

```sh
shasum -a 256 -c AlphaSync-1.5.1-147-macOS-11-12-universal.zip.sha256
```

The result should end in **OK**. After installation, the bundle’s signature integrity can be checked with:

```sh
codesign --verify --deep --strict /Applications/AlphaSync.app
```

For source-level checks from the preserved checkout:

```sh
make test
make sanitize
python3 tests/release-tests.py
```

The build hosts run newer macOS versions. Those results do not establish runtime or physical USB compatibility on every supported Mac. An earlier build was reported working on macOS 12, but the final 1.5.1 download still needs recorded physical NEO checks on that system. macOS 11 runtime testing also remains unverified. Record those results in the [manual checklist](https://github.com/koralatov/alphasync/blob/v1.5.1/tests/manual-checks.md).
