AlphaSync **1.5.1, build 147** is the final release for **macOS 11 Big Sur and macOS 12 Monterey**. It works on Intel and Apple Silicon Macs. Version 1.6 and later will require a newer macOS version.

## Download

[Download AlphaSync 1.5.1 for macOS 11 and 12](https://github.com/koralatov/alphasync/releases/download/v1.5.1/AlphaSync-1.5.1-147-macOS-11-12-universal.zip).

This release includes one Universal app download. No macOS 13–26 or macOS 27 edition is included. The ZIP contains AlphaSync and its bundled automatic-launch helper. Download the app ZIP to install it; the separate symbols ZIP is for developers investigating crashes.

## Fixes since 1.5

- Backups stop with a reconnect message if AlphaSync cannot establish the complete list of included applets and files. A partial listing cannot be reported as a complete backup.
- Replace, Clear File, and Clear All Files warnings open with Cancel as the default and initial keyboard target. The destructive button no longer receives the initial focus ring.
- The default connected window is wider so Backup, Clear, and Info fit, including the longer Clear All Files label.
- About opens without selecting a link. Its compatibility text identifies macOS 11 and 12, and its release-note and licence links remain tied to 1.5.1.
- Read-only file windows show a native read-only symbol and a Copy to Clipboard button for the complete loaded text. The native Regular and Monospaced font choices have equal widths and explanatory tooltips.

UTF-8 exports, MacASCII, UTF-8, and UTF-16 imports, recovery copies, native Mac controls, and automatic Light and Dark appearance remain available. Characters the Neo cannot represent are still rejected before a write; this release does not silently replace them.

## Install

Unpack the app ZIP, quit an older copy of AlphaSync, and move the new app into Applications. If your Mac blocks its first launch, follow the [simple installation guide](https://github.com/koralatov/alphasync/blob/v1.5.1/README.md).

## Preserved legacy version

The exact source is preserved at [v1.5.1](https://github.com/koralatov/alphasync/tree/v1.5.1) and [legacy-macos-11-12](https://github.com/koralatov/alphasync/tree/legacy-macos-11-12). Finalisation locks the legacy branch, protects the tag, and publishes an immutable release. The app, matching crash symbols, SHA-256 checksums, and build reports are retained as release assets. Future work continues on master without updating this frozen version.

## Verification

The release workflow requires successful Intel and Apple Silicon build-host checks before preparing the release. Checks cover core and native regressions, bounded sanitizers, app and helper architectures and macOS 11 deployment targets, signatures, dependencies, archive layout, matching crash symbols, menus, window layouts, and appearance changes. The newer CI operating systems are build hosts, not extra supported downloads.

Mike reports that the earlier build works on macOS 12. The final 1.5.1 ZIP still needs a recorded physical Neo check on that system; macOS 11 runtime testing remains unverified. These results do not establish every hardware combination. Keep independent known-good backups when testing writes. See the [manual checklist](https://github.com/koralatov/alphasync/blob/v1.5.1/tests/manual-checks.md) and [technical guide](https://github.com/koralatov/alphasync/blob/v1.5.1/TECHNICAL.md).
