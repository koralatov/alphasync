## What changed since 1.4.4

- Double-click a file to open it in a separate, read-only window.  You can resize the window, scroll through the complete text, and select and copy it.  Reading a file leaves its contents on the Neo unchanged.
- Choose **Regular** or **Monospaced** in the file window’s **Font** control.  Both use the system font and default size.  New file windows remember your last choice.
- **Backup**, **Clear**, and **Info** now use matching native toolbar spacing.  The available-memory count stays at the right edge when you resize the main window, and long status messages fit alongside it.
- The Universal About panel now says **For macOS 11 to macOS 26**.
- The native **Help** menu groups the built-in guide, release notes for your installed version, the licence, and support links.  It uses the standard macOS Help search and **⌘?** shortcut.
- **AlphaSync on GitHub** opens the project.  **Report Issue…** opens a GitHub report with a simple template and the app and system details filled in.  **Contact Us…** opens an email to **mike@koralatov.com**.  You can edit either message before submitting or sending it.
- The licence is available offline in Help Viewer.  Help search is rebuilt from the current guide during each build, and the starting page now gives simple instructions for reading, copying, and backing up files.

The interface follows your Mac’s Light and Dark appearance automatically.  Exports and backups use UTF-8, and imports accept MacASCII (Mac Roman), UTF-8, and UTF-16.

## Install and open

Unpack the ZIP, move **AlphaSync** to **Applications**, and open it.  Replace an older copy rather than installing both versions together.  If macOS blocks the first launch, follow the [installation and opening instructions](https://github.com/koralatov/alphasync/blob/v1.4.5/README.md).

## Testing

Automated checks cover both compiled apps, read-only file windows and font choices, native toolbar and status layouts, Help menu commands and destinations, the bundled licence, and changes between Light and Dark Mode.  They also run the existing text conversion, import-limit, backup, background-task, and Clear-warning checks.  Both downloads use the pinned release compilers.

Real Neo transfers, automatic-launch approval, and runtime behaviour on macOS 11 and 12 still need manual testing, as do interactive Help Viewer search and browser and mail hand-offs.  Back up your Neo’s files before testing transfers or clearing files.  This release remains marked as a prerelease while those checks are outstanding.  The [technical guide](https://github.com/koralatov/alphasync/blob/v1.4.5/TECHNICAL.md) explains the checks in more detail.
